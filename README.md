# Evlin — Claude Video AI for TikTok

Prompt packs for producing realistic TikTok affiliate videos with AI image and
video generators.

## Projects

- [RCH black baggy pants — mirror selfie OOTD](projects/rch-black-baggy-pants/PROMPT_PACK.md)

## Tools

- [Ageless Studio — NYO3 TikTok video editor](editor/README.md): browser-based editor that
  grades original footage and adds animated captions, tracked softgel labels, an original
  synthesised score and sound effects, then exports a 1080×1920 30 fps H.264 MP4.
  Open `editor/index.html` in Chrome or Edge.
