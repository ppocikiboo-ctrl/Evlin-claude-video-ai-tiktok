# Lilac Floral Peplum Kurung Set (Skirt Duyung) — Google Flow OOTD, 8s, bercakap

Mirror selfie OOTD 8 saat. Perempuan memperagakan set baju peplum dan skirt
duyung bercorak bunga kecil warna lilac, sambil bercakap dalam Bahasa Melayu
tentang keselesaan untuk kerja dan cikgu. Telefon menutup muka sepanjang
video.

**Gambar rujukan:** [`reference/model-mirror-selfie.png`](reference/model-mirror-selfie.png)

## Cara guna dalam Google Flow

1. **New project** → mod **Frames to Video** → model **Veo 3.1** (Quality).
2. Upload `model-mirror-selfie.png` sebagai **First frame**. Aspect ratio **9:16**.
3. Paste prompt di bawah. Jana 2–4 versi, pilih yang corak dan potongan baju paling tepat.

## Jika ada masalah

| Masalah | Penyelesaian |
|---|---|
| Ayat terpotong (ayat ini panjang untuk 8 s) | Pendekkan: `"Selesa pakai pergi kerja, cikgu pun sesuai, senang bergerak. Paling penting, cantik dan manis!"` |
| Loghat Indonesia | Tambah `Malaysian Malay accent, not Indonesian` |
| Corak bunga berkelip / berubah | Kurangkan gerakan: buang langkah ke tepi di 4–6 s, ganti dengan `she shifts her weight slightly` |
| Skirt jadi lurus / kembang dari pinggang | Ulang `mermaid skirt fitted to the knee, flaring only below the knee` |
| Gerakan "tulis whiteboard" nampak pelik | Ganti dengan `she raises her free arm to shoulder height and lowers it` |
